# Expert Mode

## Create a campaign in Expert Mode

Select **+ New Campaign** on your campaign dashboard, then select **Expert Mode:**

<figure><img src="../../../.gitbook/assets/image (1017).png" alt=""><figcaption></figcaption></figure>

Give the campaign a **name,** assign a **client,** and select either **phishing, awareness,** or **phishing and awareness**.

<figure><img src="../../../.gitbook/assets/image (1018).png" alt=""><figcaption></figcaption></figure>

Select **Create** and you will be taken to the campaign's dashboard.

<figure><img src="../../../.gitbook/assets/image (1019).png" alt=""><figcaption></figcaption></figure>

Each tab under **Main Settings** must be configured and finalized before the campaign can begin.

See our pages on the various [campaign settings](../campaign-settings/) to configure each part of the campaign. When you're finished with a tab, select **Finalize Step** to mark that tab as complete. Once all tabs are finalized the campaign will unlock.
