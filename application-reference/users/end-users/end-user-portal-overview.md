# End User Portal Overview

## Statistics

The **Statistics** page is the main dashboard of the portal. It displays the user’s [**risk level**](../risk-score.md), **training scores**, overall statistics, and a summary of completed training courses and [earned diplomas](../../templates/awareness-training-diploma.md).

***

## Awareness Training Courses

The **Courses** page lists all assigned training courses, organized by their **status**.

<figure><img src="../../../.gitbook/assets/image (944).png" alt=""><figcaption></figcaption></figure>

Users can switch between **card view** and **list view** using the buttons in the top-right corner.\
Filters on the left side allow courses to be viewed by **course type**.

***

## Account Settings

The **Account Settings** page allows users to:

* Update their **phone number**
* Set their **default language**
* **Reset their password**
* Enable **two-factor authentication**

<figure><img src="../../../.gitbook/assets/image (947).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
End users cannot change their **email address**. If an email address needs to be updated, the user must contact their **Lucy administrator**, who can modify the [recipient entry](../../../guides/quick-guides/create-your-first-campaign/campaign-setup/recipients.md).
{% endhint %}
