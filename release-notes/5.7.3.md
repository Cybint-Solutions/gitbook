# 5.7.3

## Release Notes

#### March 2026

This patch release focuses on improving stability, usability, and consistency following the changes introduced in version 5.7.

Key fixes and improvements include:

* **One-Shot Rule Scheduling:** Fixed issues that allowed invalid configurations and simplified the handling of date fields.
* **Awareness Scenario Naming:** Scenarios can now be renamed independently from their templates, providing greater flexibility when managing campaigns.
* **SSO Improvements:** Resolved several issues, including unexpected logouts from the End User Portal and improved support for direct SSO login links.
* **API Documentation:** Corrected a Swagger documentation mismatch related to victim click data.
* **Macro Triggers:** Fixed a bug affecting macro success triggers in mixed scenario templates.
* **UI Fixes:** Addressed minor interface issues, including incorrect display of the template progress bar.

Overall, this patch improves reliability and resolves several edge cases introduced after the 5.7 release.
