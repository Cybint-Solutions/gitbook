# 5.7.5

## Release Notes

**May 2026**

This patch release includes bug fixes and system improvements focused on client management, template synchronization, reporting accuracy, and version upgrade handling.

Key fixes and improvements include:

* Improved client name validation to support numbers and special characters.
* Fixed an issue where newly added languages duplicated the default language during template updates from LUST.
* Corrected inaccurate statistics in Awareness Campaign Summary reports (Report v3.0).
* Prevented version 6.0 from being downloaded on unsupported systems.
