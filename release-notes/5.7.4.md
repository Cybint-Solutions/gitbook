# 5.7.4

## Release Notes

#### April 2026

This patch release resolves several issues affecting campaign management, system operations, and administrative permissions.

Key fixes include:

* Resolved a permission error that prevented EML files from being uploaded to message templates.
* Fixed an issue that caused health checks to fail on patch versions such as 5.7.1 when run from the terminal.
* Corrected a problem that prevented administrators from managing their own notification settings.
* Fixed an issue where copied campaigns could not be stopped.

This release improves platform reliability and restores expected administrative control across several areas of the system.
