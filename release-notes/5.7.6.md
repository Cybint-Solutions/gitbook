# 5.7.6

## Release Notes

#### June 2026

This patch release includes several fixes to improve reporting accuracy, campaign management, Azure AD integration, and Awareness Training functionality.

Key fixes and improvements include:

* Resolved a discrepancy between "All Victims" CSV reports and campaign statistics displayed in Lucy.
* Fixed an issue where the Campaign Stop Date setting could generate errors in campaign configuration.
* Corrected an Azure AD Preferences issue affecting HTML content handling.
* Fixed an issue causing incorrect recipient email addresses to be recorded in Awareness campaigns.
* Resolved a problem in the EU portal where Awareness links were incorrectly loading the same content for all users.
