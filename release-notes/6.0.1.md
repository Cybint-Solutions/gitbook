# 6.0.1

## Release Notes

#### July 2026

This patch release includes fixes for training link rendering, campaign statistics, and filter dropdown visibility.

Key updates include:

* Fixed Training Link Content: Resolved an issue where End User campaigns using SSO, direct login, separate subdomains, and multiple awareness groups loaded the same training content for every awareness link.
* Portable Media Campaign Tracking: Resolved an issue where executing a "Console POST" or other EXE file template in a Portable Media Attack campaign was not recorded in campaign statistics.
* Campaign Filter Presets: Resolved an issue where Campaign Filter Presets assigned to all clients were not displayed in the "Load Pre-defined Filters" dropdown within campaign settings.
