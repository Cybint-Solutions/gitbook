# 5.7

#### January 2026 <a href="#adaptive-attack-scenarios-beta-.1" id="adaptive-attack-scenarios-beta-.1"></a>

_**Early Access release; standard workstations do not yet have access to these features.**_

## New Features

### Adaptive Attack Scenarios (Beta) <a href="#adaptive-attack-scenarios-beta-.1" id="adaptive-attack-scenarios-beta-.1"></a>

Risk Score–driven simulations automatically adjust attack complexity for each user over time. Enables continuous, personalized phishing simulations without manual segmentation or static campaigns. _During the beta phase, the feature is limited to five predefined attack scenarios._

### AURA (Beta) <a href="#aura-beta-.1" id="aura-beta-.1"></a>

AURA is an automated awareness engine designed to run end-to-end security awareness programs in Lucy with minimal administrative effort after initial setup. Administrators select topics, target audiences, and cadence, and AURA handles campaign creation, scheduling, and delivery automatically.

### Phishing via Microsoft Teams <a href="#phishing-via-ms-teams-messenger" id="phishing-via-ms-teams-messenger"></a>

Lucy now supports phishing simulations via Microsoft Teams, allowing organizations to test employee awareness directly within their daily communication platform.

### AI-Assisted Translations (Beta) <a href="#templates-translation-with-ai" id="templates-translation-with-ai"></a>

As Lucy is used across many countries and languages, we’re introducing AI Translator, a new feature that enables automatic translation of chosen templates.

## Improvements

### LDAP & Azure <a href="#ldap-and-azure-improvements" id="ldap-and-azure-improvements"></a>

A new option in the [LDAP import process](../application-reference/settings/common-system-settings/ldap-settings.md) allows administrators to mark selected **users or recipients** as “**Discarded**.” Once discarded, these users or recipients are excluded from future LDAP synchronizations.

On the [Administrative Users](../application-reference/users/) page it’s now possible to **search and sort** on LDAP server level and client level.

In Azure, the [Recipient Import](../application-reference/users/recipient-groups.md#import) page has been updated to include **3 preset filter** options: `startswith()`, `endswith()`, and `contains()`.

### Awareness Campaigns <a href="#improvements-to-awareness-campaigns" id="improvements-to-awareness-campaigns"></a>

When working on an Awareness Campaign you can now easily undo any changes you made by clicking on "**restore defaults**”. Moreover, you can now easily **change** the awareness template from **within the current campaign**, without the need to create an entirely new campaign.

### System Notifications <a href="#send-critical-system-notifications-to-email" id="send-critical-system-notifications-to-email"></a>

Admins can now set up receiving critical [system alerts](../application-reference/notifications.md) straight to their inbox, making it easier to stay informed and react quickly.

### Transactions Log <a href="#balance-transactions-log" id="balance-transactions-log"></a>

We have been getting a lot of questions about detailed transaction logs from the clients. Lucy now includes a **Balance Transactions Log**, allowing administrators to view the complete history of balance changes.
