#### Enhancements and Resolved Issues

[Template Download](../application-reference/templates/download-templates.md): Fixed an issue while downloading attachment templates.

[Crontab Execution](../application-reference/support/status/system-health-check.md): Ensured crontab restarts automatically if it fails to run after an update.
