# 5.5

## Release Notes

**Smarter simulations. Faster threat response. Safer upgrades.**

Lucy 5.5 brings meaningful updates to campaign realism, threat analysis, system safety, and user management—helping you run stronger, smoother security awareness programs.

## Detailed Feature Descriptions

#### Custom WhatsApp Smishing Templates

Inside Campaign Settings, you can now select or build WhatsApp smishing messages using built-in or custom templates. With support for Lucy variables, these messages can be personalized per recipient—enabling more realistic phishing simulations that reflect today’s attack vectors.

#### Automated Email Risk Scoring (Beta)

This intelligent new beta feature leverages machine learning to analyze incoming phishing reports. It identifies high-risk traits and assigns each message a severity score, helping security teams detect threats faster and with greater confidence.

#### Safe Upgrade Guardrail

To prevent disruptions during system upgrades, Lucy now detects whether critical operations (such as active campaigns or data processing) are running. If so, the update is blocked until it's safe to proceed, reducing the risk of post-update errors.

#### Security Enhancements

This release includes targeted fixes for high-priority security vulnerabilities. These updates improve Lucy’s resilience against phishing abuse, unauthorized access, and other emerging threats.

#### UI Fixes

Numerous small imperfections across the interface—such as spacing, alignment, or input behavior—have been cleaned up to enhance usability and polish.

#### Redesigned Admin Interface

The user management page used for creating/editing administrators now features a cleaner layout with improved field grouping, making it faster and easier to manage platform users.

#### Outlook Plugin Upgrade Complete

The outdated Outlook plugin implementation based on Microsoft REST API has been fully removed. Clients must now use the modern Microsoft 365 Outlook plugin, which is more reliable and secure.

#### Improved Campaign Launch Sync (for Master–Worker setups only)

In environments using Lucy’s Master–Worker architecture, campaign deployment now includes a pre-sync step. This ensures that campaign assets and configurations are correctly transmitted to Worker instances before activation, reducing deployment failures.
