# 5.6

## Release Notes

#### October 2025

We’re excited to share the highlights of version 5.6, bringing more control, smoother workflows, and an improved user experience.

{% hint style="warning" %}
This version is currently available only to Early Access users.
{% endhint %}

### Campaign Management

* [Expert Mode](../application-reference/campaigns/new-campaign/expert-mode.md) upgrade completed: new campaign creation flows, intuitive sidebar, grouped settings, and status indicators.
* Smarter redeploy to worker instance: system now prompts re-deployment if changes are made in Master instance after initial deployment.

### Platform Management

* [Maintenance Mode](../application-reference/campaigns/campaign-settings/advanced-settings/): temporarily lock access during updates or configuration.
* Auto-logout control: option to fully disable automatic logout.

### Learning Experience & Branding

* SCORM templates: new Preview button for easier review.
* [Training diplomas](../application-reference/templates/awareness-training-diploma.md): now fully whitelabeled under Lucy Security.

### User Interface

* Dropdowns reordered alphabetically.
* SSL configuration warnings for clearer guidance.

### Integrations

* [LDAP auto-update](../application-reference/users/recipient-groups.md) improvements for adding and removing users.
