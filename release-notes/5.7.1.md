# 5.7.1

## Release Notes

#### February 2026

Patch 5.7.1 improves stability and correctness across AURA and Campaign features. It streamlines AURA setup by hiding unnecessary fields, fixes an error when enabling Track Responses in campaigns, and enforces proper API access restrictions when the AURA license is disabled.

The patch also corrects the [Risk Score](../application-reference/users/risk-score.md) display on the recipient edit page and resolves an issue preventing attachment templates from being saved in File Attack simulations.

Overall, this update delivers a smoother admin experience and more reliable system behavior.
